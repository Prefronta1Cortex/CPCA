# Complex PCA of spike phase

Assemblies with internal timing from hippocampal reactivation events, found from sleep spikes alone. Each spike becomes an arrow whose angle is its time within the event; one complex eigen-decomposition then returns components whose weights say which cells belong together and whose angles say in what order they fire. The waking place map is used only afterwards, as the answer key.

- `docs/method.md`: the method, plainly, with the two design facts that matter (half-circle scale, read all components) and the evaluation protocol.
- `docs/plan.md`: objective, status, open problems, decisions and their evidence.
- `docs/lessons_learned.md`: what was tried before and why it was dropped.
- `docs/rendering.md`: open the docs with `Cmd+Shift+V` so formulas render.

## Results in one paragraph

On synthetic events with planted routes the pipeline recovers every route in all clean conditions (median |Spearman| 0.97–1.00 between a component's member times and the route positions), including two routes played in both directions in 15% of events with 15% of cells firing per event. On the eight hc-11 sessions (Grosmark & Buzsáki 2016), with centred components and the event duration as the half-circle scale, 21 of 118 (component, direction) tests match the place map in sleep after the novel maze (POST; chance ≈ 6) against 4 of 104 in sleep before it (PRE; chance ≈ 5); the effect is carried by the two sessions with 50 or more place cells. Against the other methods run with their authors' procedures (`docs/baselines.md`), seqNMF matches cPCA when replays are common but not at 15% replay and finds no map-ordered factor on hc-11 (its main factor is the population burst), the Maboudi HMM detects sequential events but not which map they belong to, and only its behaviour-labelled latent space shows the POST/PRE dissociation that cPCA shows label-free. Full tables: `results/summary.md`, `results/synthetic/summary.md`, `results/baselines/summary.md`; figures: `figures/`.

## Quick start

```bash
conda create -n CPCA --override-channels -c conda-forge python=3.12 numpy scipy matplotlib scikit-learn h5py pytest pip
conda activate CPCA
pip install -e .
pytest -q

python scripts/run_synthetic.py        # ~1 min: planted routes, 8 conditions x 3 draws
python scripts/run_hc11.py             # ~3 min: all sessions, POST and PRE, 4 variants
python scripts/summarize.py            # tables -> results/summary.md, figures -> figures/
python scripts/plot_component_circle.py  # components and data on the unit half-circle

# method comparison (needs the extra packages: python -m venv --system-site-packages .venv; .venv/bin/pip install hmmlearn seqnmf "setuptools<80")
.venv/bin/python scripts/run_baselines.py synthetic     # ~25 min, resumable per condition
.venv/bin/python scripts/run_baselines.py hc11          # ~1.5 h, all sessions, POST and PRE
.venv/bin/python scripts/summarize_baselines.py         # results/baselines/summary.md, figures/baselines_*.png
```

Minimal use of the method on your own events:

```python
import numpy as np
from cpca import fit

# times_ms: (events, cells, spikes) in ms from each event window's start, NaN where no spike
# T_ms: each event's duration (the half-circle rule), or one number for all events
result = fit(times_ms, T_ms, center=True, scale=True)
result["n_kept"]                      # components above the noise bound
result["readouts"][0]["times_ms"]     # relative firing time of each member cell in component 1
result["readouts"][0]["weights"]      # its weight (participation)
```
